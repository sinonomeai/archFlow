# 2026-11-13 MVP 主链路实现记录

> 关联：`specs/待做清单.md` P0-01 ~ P0-19。
> 结论：MVP 主链路已在本地端到端跑通；仍有三项明确缺口（图片解析、指标看板、Supertest 业务用例）。

## 1. 已实现

### 契约与数据库
- `RunStatus.waiting_input`、`runs.metadata`、`agent_states.version`、SSE `interrupt`、`run-start.resume`。
- 图契约采用 P0-13 的 strict `Graph`（无坐标），会话草稿 / 消息快照用 `LooseGraph` 兼容旧数据。
- 迁移 `20261112000000-RunMetadataAndAgentStateVersion` 已在真实 PostgreSQL 执行。

### API 模块
- `auth`：注册、登录、刷新（Redis hash + 轮转）、登出、me；access 15min / refresh 30d。
- `project` / `conversation` / `asset`：CRUD、项目树聚合、消息游标分页、草稿乐观锁、fork。
- `file`：multipart 上传、20MB + 扩展名白名单、MinIO、状态查询、Range 下载、删除。
- `rag`：文本切片、Embedding、pgvector topK 检索、citation。
- `run`：202 受理、内存事件缓冲 10min、`Last-Event-ID` 重放、缓冲失效快照合成、取消、HITL 中断/恢复。
- `system`：`/health`、`/ready`。
- 全局：Zod 校验、统一 ApiResponse、traceId、pino-http、`Idempotency-Key`、越权 404。

### Agent
- 手写 workflow：约束提取（Function Calling + Zod）→ 缺失约束卡片（HITL）→ 架构生成（JSON + Zod + 最多 2 次修复）→ 流式说明 → done。
- 模型：`deepseek-flash`（OpenAI 兼容协议）；thinking 模式不支持强制 `tool_choice`，改用 `auto` + 提示词约束。
- 无 Key 时提供本地保底图，保证流程可演示。

### Web
- 真登录/注册、内存 accessToken + 静默刷新、401 重试。
- 侧栏项目树、知识库上传、资产点击开新会话。
- 聊天：SSE 打字机、状态提示、约束卡片、停止生成、刷新后自动接回活跃 run。
- 画布：React Flow + Dagre、自动布局、保存资产、恢复快照、fork。
- 已删除 `app/api/mock` 与 `lib/mock-*`。
